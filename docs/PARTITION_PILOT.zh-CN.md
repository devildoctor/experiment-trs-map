# ATXN2 / ABCA7 单元划分

新增 `--locus-model` 和 `--core-output`。前者应用冻结词典，后者把主页面简化为模板、排列顺序、长度和实际碱基；原有图、原始记录和审计输出保存在 `audit/`。不指定模型时继续沿用原来的发现模式。

## 如何划分

1. 根据目录固定参考区间。ATXN2 使用 `chr12:[111598950,111599019)`；ABCA7 使用 `chr19:[1049432,1050044)`，后者仍是候选窗口。
2. 保留提供的 BAM 中全部记录类型。逐条记录提取连续的实际序列；局部侧翼锚点不足时，保留 CIGAR 投影片段和覆盖状态，不跨记录拼接。
3. 冻结词典的 ID、碱基、长度和参考正向相位。ATXN2 使用 CTG、TTG（均为 3 bp）；反向互补视图对应 CAG、CAA，且整个单元顺序反转。ABCA7 沿用既有目录的 25/26 bp 模板。应用模式不从参考或新样本自动增加、旋转或重命名模板。
4. 逐序列进行动态规划，允许替换、插入、缺失、末端残片及未知片段。每个单元保存实际切片；模板匹配不替换观测碱基。≤6 bp 的短单元枚举所有起点，避免发生单碱基替换后因缺少精确种子而漏配；较长模板仍使用种子候选搜索。
5. 同时输出模板长度和实际长度。实际单元与模板不一致时，记录编辑距离；未知和末端残片单独标识。低频实际序列保留在导出表中，不因不足 10% 而消失，也不自动写入冻结词典。
6. 保留最佳划分和一个备选；并列时标记歧义。分解代价是描述性代价，未校准为错误概率。

现用代价：未知每碱基 1；完整单元 `0.1 + min(3,0.6×模板长度)×编辑距离 + 2×长度差绝对值`；精确末端残片 0.2。候选允许的编辑数和长度偏差依照原程序的 HiFi/ONT 搜索范围。这里没有拟合新的平台错误模型，也没有完成低频结构的联合统计推断。

## 输出

- `index.html`：直接打开，筛选样本和平台，切换方向；色块与逐单元表联动。
- `motifs.tsv`：冻结模板 ID、长度和碱基。
- `observed_units.tsv`：全部实际单元的长度、碱基及去重观测数；参考不计入观测支持。
- `partitions.tsv`：每个观测片段的有序划分，可与 `audit/` 中片段 ID 对应。
- `summary.json` / `verification.json`：摘要和验收。
- `audit/`：原始记录、完整图、备选方案、参数、来源哈希和输入词典副本。

相邻色块只有在实际碱基、模板及匹配状态相同的情况下才合并显示。界面中的分子身份采用样本、来源命名空间和 QNAME 去重，不能证明物理模板独立性。MAPQ=255 表示质量值不可用，不能进入合格主比对支持；记录本身仍保留。

## Slurm 运行

将项目源文件冻结到独立 `RUN_DIR`，生成 `SHA256SUMS` 后提交：

```bash
sbatch --export=ALL,RUN_DIR=/absolute/path/to/frozen/run \
  --output=/absolute/path/to/frozen/run/job-%j.log \
  /absolute/path/to/frozen/run/slurm/partition_pilot.sbatch
```

任务在计算节点执行单元测试、合成 BAM 集成检查、两个点位的真实数据处理和逐片段重建核验。原始项目输入和旧结果不覆盖。

## 当前边界

试跑使用已有的位点 BAM。读取阶段不再过滤次级比对，但不能恢复此前 `-F 256` 删除的记录，也不能证明位点窗口外的竞争比对齐全。完整竞争定位核查应从完整 BAM 先收集候选 QNAME，再取这些 QNAME 的全部主、次级和补充比对；应在计算节点执行，保留来源和切割命令。

`vntranchors.py` 同时修复了失败原因传播：当没有可接受锚点对时，早先的弱模板不能掩盖后面的竞争定位冲突。此修复保护严格锚点流程；当前简洁结构页仍是带覆盖标记的观测划分视图，并不据此声明已完成全基因组唯一定位。

这些结果用于检查单元组成和排列。模板长度、实际切片长度和生物学拷贝数是不同概念；没有把单元数输出为基因型或疾病结论。ABCA7 的固定词典只是本次可复现的初始模型，后续可依据确切观测提出新模板，验证后升级版本。
